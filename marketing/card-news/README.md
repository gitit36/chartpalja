# 차트팔자 카드뉴스 — 7장 구성

규격: Instagram 4:5, 1080×1350 SVG  
목표: 첫 장의 사회적 증거로 멈추게 하고, 실제 화면을 단계적으로 공개해 마지막 CTA까지 넘기게 한다.

## 업로드 순서와 리텐션 장치

1. **하루 만의 성과** — `133명 / 270개`를 가장 크게 노출
   - 다음 장 예고: “왜 한 사람당 2개 넘게 만들었을까?”
2. **100년 인생 차트** — 가장 강한 제품 효용을 실제 화면으로 증명
   - 다음 장 예고: “선 하나로 끝이 아닙니다”
3. **보조지표** — 필요한 기운·변화의 파도·귀인의 도움·오행 균형도
   - 다음 장 예고: “내 사주 안에서는 무엇을 볼까?”
4. **사주 정보 상세** — 타고난 기운의 관계, 타고난 복과 걸림돌
   - 다음 장 예고: “둘이 겹치면?”
5. **궁합 흐름** — 한 점수가 아닌 두 사람의 연도별 흐름
   - 다음 장 예고: “좋은 결과는 혼자만 보기 아깝죠”
6. **공유 기능** — 카카오톡 공유·링크 복사·이미지 저장
   - 다음 장 예고: “다음 차트의 주인공은”
7. **CTA** — `차트만 먼저 보기 →`

## 콘텐츠 설계 원칙

- 1~3장에서 숫자 → 핵심 화면 → 분석 깊이를 빠르게 증명한다.
- 각 장은 한 가지 메시지만 전달한다.
- 모든 장 하단에 다음 장의 보상을 예고한다.
- 기능 설명보다 실제 화면 비중을 높인다.
- 사용자의 이름·생년월일은 카드에서 가리거나 일반 문구로 교체한다.
- `133명`은 무료 이용자를 포함하므로 “고객”보다 “이용자”로 표현한다.
